# Gates

Regenerated by `python scripts/gates.py` on 2026-10-31 at commit `d2cf63c`. Every number in this file is measured by that command. Nothing else in the repository may state a figure this file does not contain.

A gate is a comparison against a named baseline. No agent is connected to the critic before it beats its baseline, and an agent that has not passed its gate abstains at runtime and keeps its gate report.

No figure in this table is a performance claim. The per series figures recorded in the plan and in `src/agents/variant.py` are +0.643 on polymerase and +0.394 on scFv for GC3 alone. This run measures +0.643 and +0.394. Any divergence between the two is a change in the feature code and should be explained before it is accepted.

The artifact under test is `models/agent_c_variant_ranker.joblib`, a XGBRanker over 7 features a synonymous substitution can move, fitted on 83,338 sequences in 4,780 query groups from 2 sources: cambray2018 74,900, goodman2013 8,438.

Two independent sources is the point of the secondary gate, because it separates two explanations of a failure. If the ranker worked on one library and not the other, the result would be about that library's scaffold. It does not: both are short designed regions fused to a reporter, both train a model that orders their own held out groups well, and neither carries to whole genes. That points at the fragment, not the scaffold.

Its training sequences are 33 to 96 nt long. The Welch ORFs are 843 and 1,725 nt, so every figure in the table above is an extrapolation in sequence length, and the agent says so in its own domain check at runtime.

The secondary part of Gate C, on 956 held out query groups from the training source: mean Kendall tau within group +0.156 for the model against -0.076 for GC3 alone, so inside its own domain the model beats the baseline.

What this run did establish, and it is not nothing: unlike the tier model, the ranker is positive on both Welch series, so it no longer orders a synonymous series backwards. What it did not do is beat GC3, which is the bar, so the agent abstains and the redesign loop keeps ranking on the tier model with the GC3 corroboration check as its guard.

The overall figure, -0.350, is negative while both series are positive, which is not a contradiction. The two series are different proteins measured on different scales, so pooling them compares a polymerase variant against an scFv variant, which is a between gene comparison this agent has no opinion about. The per series figures are the ones the gate is defined on.

Nothing here was tuned against Welch and nothing may be. Welch is the held out external test set, so choosing between models by their Welch score would turn the gate into a training signal and there would be no external evidence left in the project.

The length mismatch is measured rather than assumed. Scoring the same model on only the first 96 nt of each Welch ORF, which is the window it was trained on, gives polymerase -0.227 against +0.018, scFv +0.212 against +0.183. The mean per series change is -0.108. Matching the window does not help, so the gap to GC3 is not merely an extrapolation in length: what the model learned on a 32 codon reporter fragment does not carry to whole genes. Training data from whole constructs is the thing to try next, not a different objective or more trees. This is a diagnostic and not the gate.

## Gate D. mRNA structure and initiation

Agent D is the one agent blocked by a missing input rather than a missing dataset. `feature_table_v4.csv` carries Boel's own Gz48v and Gave48, computed over the expression vector's 5' untranslated region, and the application cannot compute them from a pasted coding sequence because it does not know the vector. Declaring the vector makes the initiation window computable. The gate has two parts: beat the GC of the first 48 nt alone at predicting the lowest expression band, which is the baseline that catches a folding feature that is really a GC feature under another name, and show that leader plus insert folding beats insert only folding on the same rows. The second part is a test of the interface change rather than of the model.

### The folding unit test, which this gate depends on

Before anything is trained, the project's own folding code is checked against measured expression on Cambray 2018, over 74,900 variants in 4,126 groups of synonymous variants. Cambray varies the 5' region against a fixed reporter and measures protein directly, so a bug in the folding implementation shows here.

| Quantity | Against protein level, overall | Within synonymous groups |
| :--- | ---: | ---: |
| `head_folding_48`, real ViennaRNA | 0.155 | 0.142 |
| `genewide_folding_avg`, real ViennaRNA | 0.035 | n/a |
| GC of the first 48 nt | -0.121 | -0.114 |
| GC3 | n/a | -0.063 |

**The folding code passes.** A less negative 5' folding energy, meaning less structure, goes with more protein, and within synonymous groups it is the strongest of the three, which is the direction and the ordering Cambray reports. It is worth noting that GC3 runs slightly negative here while it is strongly positive on Welch: the two libraries are different regimes, which is part of why Agent C does not transfer.

**The retired proxy is confirmed to be GC.** `folding_energy`, the GC derived proxy, correlates with the GC of the first 48 nt at exactly -1.000 and with the real folding energy at only 0.351. A correlation of -1.000 is not a strong relationship, it is an identity: the proxy is a monotonic function of that GC. Retiring it from Agent D loses nothing and stops one quantity being counted twice under two names.

**Status: passed.** Gate D passed. AUROC 0.612 against 0.584 for the GC of the first 48 nt alone, a difference of +0.029 with a bootstrap interval of +0.011 to +0.047; leader plus insert 0.612 against insert only 0.603, a difference of +0.009 with an interval of +0.001 to +0.017.

Each single descriptor is scored in whichever direction suits it, because AUROC is direction sensitive and beating a mis-signed baseline is not beating the baseline. On this data a GC rich 5' region is more likely to land in the lowest band, which is the direction the structure argument predicts: a GC rich 5' region folds more tightly and initiates worse. The direction is recorded rather than assumed because the first version of this harness assumed the other one, which made the baseline look weaker than it is.

The margins are tested rather than eyed, by a paired bootstrap over the same rows. Against the GC baseline the difference is 0.029 with a 95 per cent interval of 0.011 to 0.047, so the first clause passes. Against the same model without the leader the difference is 0.009 with an interval of 0.001 to 0.017, so the second clause passes.

For reference, on the Boel table itself: the authors' own Gz48v, which folds leader plus insert with RNAstructure, tracks the expression score at rho 0.177, while `head_folding_48`, the servable insert only counterpart computed here with ViennaRNA, reaches 0.141.

## The critic

The critic is trained on out of fold opinions from the agents over the clusters outside the pool, and evaluated once, on the pool, against the best single agent. The agents that feed it are Agent A and Agent D, the two that produce a distribution for a single submitted sequence. Agent B does not exist, and Agent C ranks variants within a gene so it has no opinion about a single sequence by construction.

**Status: failed.** The critic does not beat the best single agent on the reserved pool, so the single agent is shipped for the tier and the critic is kept for the agreement score and the abstention policy only. That is the outcome the plan names as legitimate.

**The abstention policy, which is the part worth having.** The conflict threshold is chosen on the pool by the trade off between how often the system answers and how often it is right when it does, not by taste. At a divergence of 0.108 the system answers 52 per cent of inputs at 0.571 accuracy on those, against 0.543 when it answers everything.

That is a lift of +0.028 for declining 48 per cent of inputs. The mechanism works and the signal is weak: two agents, one of which has not passed its own gate, do not disagree in a way that reliably marks the cases where the answer is wrong. ## Leakage

The one mistake that would invalidate everything: the critic is trained on the specialists' predictions, so if a specialist's training rows overlap the critic's training or evaluation rows, the critic learns that the specialist is more accurate than it is, and the agreement score becomes meaningless in exactly the cases it exists for. The guard is to cluster the union of every dataset once, assign every row a cluster id and a source label, reserve the critic pool by cluster, and never split by row anywhere.

No critic has been trained and none can be until the clustering above is unblocked. `tests/test_leakage.py` asserts that no critic model is loaded while the critic pool is unreserved, so this cannot be done by accident later.
